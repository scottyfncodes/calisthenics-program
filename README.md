# Morning Calisthenics

A self-contained, single-file 12-week bodyweight calisthenics program. No build step, no dependencies — open `index.html` in a browser or host it as a static site (e.g. GitHub Pages).

## Features

- 84-day program across 4 progressive phases (Foundation → Building → Strength → Performance)
- Daily push / legs / core / pull / full-body circuits, plus mobility and recovery days
- Animated stick-figure demos and form cues for every exercise
- Per-exercise work timers with an audio cue on completion
- Progress (current day + completed days) saved locally in the browser via `localStorage`

## Running it

Just open `index.html` directly, or serve the folder with any static file server:

```
npx serve .
```
